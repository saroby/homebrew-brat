# Brat

Public installers and update metadata for Brat. Application source is maintained in a private repository.

## Install on Apple Silicon macOS

```sh
brew tap saroby/brat
brew install --cask brat
```

Or download the signed DMG from [Releases](https://github.com/saroby/homebrew-brat/releases). Brat checks for updates and downloads them when you choose **Upgrade**; restart to apply the downloaded version.

## Install on Windows

Download the x64 EXE installer from [Releases](https://github.com/saroby/homebrew-brat/releases). Every stable release includes installers and update metadata for both supported platforms.

This repository contains release binaries, update metadata and the Homebrew cask only. No application source or service credentials are published here.
